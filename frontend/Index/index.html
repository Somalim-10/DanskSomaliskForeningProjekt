Velkommen til Dansk-Somalisk Forening

Vi bygger bro mellem dansk og somalisk kultur gennem fællesskab, integration og meningsfulde arrangementer for alle generationer.

Vores Formål

🤝 Integration

Vi skaber mødesteder hvor dansk og somalisk kultur mødes, og hvor nye fællesskaber kan opstå gennem dialog og fælles oplevelser.

🎉 Kulturelle Events

Fra somaliske middage til danske højtider - vi arrangerer begivenheder der fejrer begge kulturer og samler mennesker på tværs.

🌍 Fællesskab

Et stærkt netværk hvor medlemmer støtter hinanden, deler erfaringer og skaber varige venskaber på tværs af generationer.
